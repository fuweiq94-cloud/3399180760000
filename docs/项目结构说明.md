# D3QN Snake AI - 项目结构详解

## 📁 模块化目录结构

本项目采用**模块化设计**，将代码按照功能职责拆分到不同的子包中，便于维护和扩展。

```
src/                              # 源代码主目录
├── envs/                         # 环境模块 - 游戏环境定义
│   ├── __init__.py              # 包初始化文件
│   └── snake_env.py             # Snake 游戏环境实现
│
├── models/                       # 模型模块 - 神经网络架构
│   ├── __init__.py              # 包初始化文件  
│   └── d3qn_network.py          # D3QN 神经网络
│
├── agents/                       # 代理模块 - 强化学习算法
│   ├── __init__.py              # 包初始化文件
│   └── d3qn_agent.py            # D3QN 智能体实现
│
├── utils/                        # 工具模块 - 辅助功能
│   ├── __init__.py              # 包初始化文件
│   ├── gui.py                   # GUI 界面 (Tkinter)
│   └── visualize.py             # 可视化工具
│
├── data/                         # 数据模块 - 数据处理 (预留)
│   └── __init__.py              # 包初始化文件
│
└── __init__.py                  # 主包初始化
```

## 🔍 各模块详细说明

### 1️⃣ **envs/** - 环境模块

**用途**: 定义强化学习环境接口（遵循 Gymnasium 规范）

**包含文件:**
- `snake_env.py`: Snake 游戏环境
  - 继承自 `gymnasium.Env`
  - 实现游戏逻辑（蛇的移动、碰撞检测、食物生成等）
  - 提供两种观察模式:
    - `vision`: 基于局部视图的 10 维向量
    - `state`: 完整的网格状态 (grid_size × grid_size)
  - 渲染功能：pygame 可视化

**主要类:**
```python
class SnakeEnv(gym.Env):
    def __init__(self, grid_size=20, observation_type='vision')
    def reset(self, seed=None, options=None)
    def step(self, action)
    def render(self)
```

---

### 2️⃣ **models/** - 模型模块

**用途**: 定义神经网络的架构和层结构

**包含文件:**
- `d3qn_network.py`: D3QN 网络实现
  - 继承自 `torch.nn.Module`
  - 卷积层用于特征提取
  - Dueling 架构分离 Value Stream 和 Advantage Stream

**主要类:**
```python
class D3QN(nn.Module):
    def __init__(self, input_dim=10, num_actions=4, ...)
    def forward(self, x)
```

**网络结构:**
```
Input → Conv1d(16) → ReLU → BN
       → Conv1d(32) → ReLU → BN
       → Flatten → FC Shared
                                ├→ FC Value → V(s)
                                └→ FC Advantage → A(s,a)
Output: Q = V + (A - mean(A))
```

---

### 3️⃣ **agents/** - 代理模块

**用途**: 实现强化学习算法和智能体逻辑

**包含文件:**
- `d3qn_agent.py`: D3QN 智能体
  - 封装了主网络和目标网络
  - 管理经验回放缓冲区 (Replay Buffer)
  - 实现 Double DQN 训练更新逻辑
  - 管理探索率 (epsilon) 调度

**主要类:**
```python
class D3QNAgent:
    def select_action(self, state, train=True)      # 选择动作
    def store_transition(self, ...)                  # 存储经验
    def optimize_model(self)                         # 训练优化
    def save(self, path)                             # 保存模型
    def load(self, path)                             # 加载模型
```

**核心算法:**
- Experience Replay (经验回放)
- Double Q-Learning (双 Q 学习)
- Epsilon-Greedy Strategy (ε-贪心策略)
- Target Network (目标网络)

---

### 4️⃣ **utils/** - 工具模块

**用途**: 提供辅助功能、GUI 界面和可视化

**包含文件:**
- `gui.py`: Tkinter 图形界面
  - 启动/停止控制
  - 实时显示得分和统计
  - 模型验证控制台
  
- `visualize.py`: 可视化辅助函数
  - 绘制训练曲线
  - 生成性能报告图表

**主要功能:**
```python
class SnakeGUI:
    def start_training()       # 启动训练
    def stop_training()        # 停止训练
    def update_stats()         # 更新统计数据

def plot_training_curves(data) # 绘制训练曲线图
def save_training_report(fig)  # 保存训练报告
```

## 🚀 脚本目录 (`scripts/`)

**用途**: 可执行的启动和训练脚本

**包含文件:**

| 文件名 | 功能 | 说明 |
|--------|------|------|
| `start.ps1` | PowerShell 启动器 | ⭐推荐使用，自动检查环境并启动 |
| `start_training.bat` | 批处理启动器 | Windows CMD 兼容 |
| `train.py` | 训练脚本 | 主训练循环，支持断点续训 |
| `demo.py` | 演示脚本 | 测试已训练的智能体 |
| `eval_model.py` | 评估脚本 | 分析模型性能指标 |
| `停止训练.bat` | 停止脚本 | 创建 STOP 文件请求优雅停止 |

## 🎯 设计优势

1. **清晰的分层**: 每层职责明确，易于理解和维护
2. **高度解耦**: 模块间通过标准接口通信，替换组件不影响其他部分
3. **易于扩展**: 添加新环境/模型/算法只需新增对应模块
4. **可测试性**: 每个模块可以独立测试
5. **符合规范**: 遵循 Python 项目最佳实践

## 📝 扩展指南

要添加新功能:

1. **新环境**: 在 `src/envs/` 新建 `.py` 文件
2. **新模型**: 在 `src/models/` 新建网络类
3. **新算法**: 在 `src/agents/` 新建 Agent 类
4. **新工具**: 在 `src/utils/` 添加辅助函数
5. **新数据**: 在 `src/data/` 实现数据加载器

所有新模块都应在对应的 `__init__.py` 中导出。
